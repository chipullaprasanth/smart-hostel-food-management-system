Zero Waste Target

The project's primary mission is to eradicate hostel food wastage. By aligning kitchen preparation requirements dynamically with student headcount data, we reduce raw food excess, manage pantry inventory, and establish donation pipes for surplus resources.

Telemetry & Predictions

Operating with a python back-end utilizing SQLite databases, the software records history metrics, log details, user registrations, and parses data using linear regression trends to output forecasts. Frontend charts dynamically adapt using Javascript.

Senior Enterprise Design

Refactored to meet premium security constraints, clean MVC architecture, dynamic chart visualization models, session check parameters, and database query bindings.
